# BLOFY – Buffer Free Auto Publishing

This setup uses **Buffer's free GraphQL API** + **GitHub Actions**, without any paid publishing subscription.

## First-time setup (required)

1. Buffer → **Settings → API** → **Create API key**.
2. Open [BLOFY-PLAYER-NEXT repository secrets](https://github.com/i20sss20-maker/BLOFY-PLAYER-NEXT/settings/secrets/actions) → **New repository secret**.
3. Set **Name:** `BUFFER_API_KEY` and **Secret:** paste the key from Buffer. Do not place it in code, issues, public chat or commits.
4. In [GitHub Actions](https://github.com/i20sss20-maker/BLOFY-PLAYER-NEXT/actions/workflows/blofy-buffer-auto-post.yml), choose **Run workflow** with `check` to verify the connections. Review the logs.
5. First X test was successfully **published** on 2026-11-12 12:50 Riyadh at https://x.com/1471967658421723138/status/2120816496125337896. Scheduled runs continue automatically. Do not rerun one-time modes unless another post is intended.

## Publishing schedule (Saudi Arabia)

- **X @i20au:** eight posts/day, approximately every two hours, at 09:30, 11:30, 13:30, 15:30, 17:30, 19:30, 21:30, 23:30 (timing may vary because GitHub scheduled workflows can be delayed). Each text is varied using a content bank.
- **Instagram i10s01:** a personal account cannot automatically publish. On 2026-11-12, the first notification post **failed** because the Buffer account has **no registered mobile device**. The scheduler now skips personal Instagram when no device is registered. Fix by installing the Buffer app and enabling push notifications, or converting the Instagram account to a Professional account and reconnecting Buffer; the latter enables automatic feed posts when requirements are met. Instagram poster URLs are JPEG 1080x1350 (4:5) to avoid feed aspect-ratio rejections.
- **TikTok i.20as:** one JPEG image post per day beginning **2026-11-28**; a trial JPEG image post has already been accepted into Buffer's automatic publishing queue for November 28 18:30 Riyadh. The Metricool calendar through November 27 was fixed after its first attempt failed because TikTok rejected PNG photos. Remaining Metricool posts were changed to JPEG (12) or MP4 promo video (4). One fixed photo replacement for Nov 12 at 13:15 remained pending when checked; do not claim a successful public post before confirming its status.
- Current image assets are hosted by Metricool, with original artwork in `marketing/2026-11/`. Original 11.6s silent vertical videos are in `marketing/videos/`; generated by `marketing/buffer/build_video.py` via GitHub Actions.

Buffer's free account holds at most **10 scheduled posts per channel**. This job does not create a post when the channel queue has 9 or more pending items, and it checks the API before creating anything. The account/API also has usage limits. If the platform rejects a media post, see GitHub Actions logs.

## Safety

- The automation selects only the matching X username `i20au` and TikTok account `i.20as`; it avoids guessing among multiple Instagram channels.
- The repository contains no Buffer token.
- Never promise copyrighted channels, specific film libraries, guarantees of availability, or licensed content unless independently verified.
- `post-x-now`, `post-instagram-now`, and scheduled jobs are **real publishing operations**, not simulations. `check` reads only.

## Files

- `content.json`: approved advertising copy and hosted poster URL list
- `publish.py`: API connection, account lookup, duplicate checks and scheduling
- `.github/workflows/blofy-buffer-auto-post.yml`: GitHub Actions scheduler

For Buffer documentation: https://developers.buffer.com/guides/getting-started.html

## Automated status checks

GitHub Actions checks Buffer post statuses at **08:20 Riyadh time every day** and prints X public post URLs, queued items and any errors in the workflow logs. On workflow pushes it runs read-only checks; only scheduled or explicitly dispatched posting modes can create posts. Metricool publishing errors require a separate Metricool calendar inspection.
